# Retired: Full-FOV foveal canvas (2026-10-21)

The **Full-FOV foveal canvas (experimental)** patch targeted only Steam Link `2.0.20/5001812`.
That base was retired on 2026-10-21, so the patch, its bundled `libgxr_foveal_canvas.so` and
layer manifest, the `extensions/foveal-canvas-layer/` source tree, its tests and the
`FovealCanvasMorpheAudit` runner were removed. `Verify-Catalogs.py` was deleted because it
asserted the removed catalog entry.

This directory stays as the historical record of the experiment: the loader-crash RCA, native
build notes, Morphe validation logs and the crash fix that the shipped layer needed. Nothing
here is a current procedure.
