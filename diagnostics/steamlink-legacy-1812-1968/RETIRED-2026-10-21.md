# Retired: Steam Link 2.0.20/5001812 and 2.0.21/5001968 support (2026-10-21)

The Steam Link VR bases `2.0.20/5001812` and `2.0.21/5001968` were retired on 2026-10-21.
Their compatibility entries, native layout tables, patch guards, test pins and catalogs were
removed; only `2.0.20/5001712` and `2.0.23/5002363` remain supported.

This directory stays as the historical evidence record for those builds: the adaptation and
validation notes, decoded-byte receipts and the original audit procedure. The tracked harness
scripts (`Run-MorpheAudits.py`, `Package-Local.py`, `derive_color_layouts.py`) were deleted
because they only applied patches to the retired bases. Nothing here is a current procedure;
see `README.md` in the repository root and `TECHNICAL_REFERENCE.md` for the supported set.
